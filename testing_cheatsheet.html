🧪 Software Testing Cheatsheet

📋 Testing Methodologies

Unit Testing

  • Tests individual functions/methods
  • Fast execution, isolated tests
  • Mocks external dependencies

Integration Testing

  • Tests module interactions
  • Database, API, service tests
  • Validates data flow

E2E Testing

  • Full user workflow simulation
  • Browser automation
  • Real environment testing

🎯 Test Case Design

Techniques

  • Equivalence Partitioning: Divide inputs into groups
  • Boundary Value: Test edge cases
  • Decision Table: Combinations of conditions
  • State Transition: Test state changes
  • Error Guessing: Experience-based testing
  • Exploratory: Simultaneous learning & testing

🐛 Bug Severity/Priority

Severity Levels

Critical System crash/data loss
High Major functionality broken
Medium Feature partially works
Low Minor UI/cosmetic issues

Priority Levels

  • P0: Fix immediately
  • P1: Fix in current sprint
  • P2: Fix in next release
  • P3: Fix when possible
